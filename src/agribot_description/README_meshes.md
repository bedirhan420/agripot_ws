# meshes/

Bu klasor bos birakilmistir. Proje dokumaninda belirtildigi gibi gorsel
mesh'ler (govde, tekerlek, kol linkleri icin daha detayli .stl/.dae
dosyalari) Blender'da tasarlanip buraya yerlestirilecektir. Iskelet
asamasinda URDF/Xacro dosyalari basit geometrik primitifler (box,
cylinder) kullanir; bu, fizik/collision testlerini mesh beklemeden
baslatmayi saglar.
